# ml-research-infrastructure

Shared research tooling built for my [AI Research Ecosystem](https://github.com/shashwat-158) collection — providing experiment tracking, config-driven runs, and a common evaluation framework across multiple ML agents.

**Status:** in progress

## Planned components
- [ ] Experiment tracker (config + seed → result, queryable)
- [ ] Config system (runs driven by files, not hardcoded values)
- [ ] Dataset versioning
- [ ] Checkpoint manager
- [ ] Shared evaluation framework
- [ ] Unified logging
- [ ] Benchmark runner
- [ ] GPU monitoring
- [ ] Results database
